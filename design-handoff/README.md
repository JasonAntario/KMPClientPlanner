# Handoff: Куфар Блокнот — desktop MVP (KMP / Compose Multiplatform)

## Overview
Приложение для самозанятых: учёт клиентов, услуг (занятий) и оплат. Категории услуг: базовая, репетитор, тренер, бьюти-мастер, тату-мастер. Этот пакет покрывает **только объём MVP** и **приоритетно десктопную раскладку** (KMP desktop; мобильные таргеты — те же экраны с заменами, описанными ниже).

## About the Design Files
Файлы в пакете — **дизайн-референс, сделанный в HTML**. Это не продакшн-код: HTML описывает намеренный вид, структуру и поведение. Задача — **воспроизвести эти экраны в целевой кодовой базе** (Kotlin Multiplatform + Compose Multiplatform: `commonMain` UI, десктопный таргет как основной), используя её собственные паттерны. HTML не переносить и не встраивать.

Открыть референс: `Куфар Блокнот - Desktop MVP.dc.html` (рядом должны лежать `support.js` и папка `_ds/`).

## Fidelity
**High-fidelity.** Цвета, типографика, отступы, радиусы и тени финальные — брать их из токенов (`_ds/organic-.../styles.css`). Данные в макетах — демонстрационные. Иконки — Lucide, stroke-width 2.75.

## Core components (сделать в commonMain)
1. **NavigationRail** — 248px, фон surface, паддинг 24/16; бренд Caprasimo 19 сверху; пункты: иконка 18 + текст 14, паддинг 11/14, radius 999; активный — фон accent, текст bg; снизу подпись «<категория> · v1.0.0» 11px muted.
2. **StatusButton** — pill-кнопка: иконка 16 + текст 13–15. Два вида: `PaymentStatus` (иконка «купюра») → *Оплачено* / *Не оплачено*; `SessionStatus` (иконка «календарь») → *Проведено* / *Запланировано*. Цвета — по семантике выше. Внешний вид **не зависит** от выделения строки.
3. **ServiceRow** (строка ленты) — grid `124px 1fr 176px 352px`, паддинг 24/28, radius 26, фон surface, gap 18. Колонки: время (Caprasimo 26) · имя 18 + подпись 13 muted (услуга · длительность · место) · сумма 17 tabular · два StatusButton. Выделенная строка: shadow-md + обводка 2px accent (кнопки те же).
4. **ClientRow** — аватар-кружок 38–40 (инициалы, Caprasimo 15, фон accent-200/accent-2-200/neutral-300) + имя 15; без вторичной строки. Секции по первой букве (11px, letter-spacing .08em, muted).
5. **Card** — фон surface, radius 32, паддинг 13.2, gap 8.8; `kicker` 10px uppercase accent, `title` Caprasimo 17.
6. **SegmentedControl** — pill-контейнер с бордером divider, опции 13px, паддинг 7/12; выбранная — фон accent, текст bg.
7. **Buttons** — primary (fill accent, текст bg; hover accent-600, active accent-700), secondary (бордер divider, hover text@7%), ghost (текст accent), icon 36×36.
8. **Dialog** — оверлей neutral-900@45–50%, панель surface, radius 32, паддинг 17.6, shadow-lg; заголовок Caprasimo 20; действия справа, деструктивное — слева (ghost).
9. **Field / Input / Textarea** — фон surface, бордер divider, min-height 36, шрифт 14, radius 999 для однострочных; **textarea — radius 16, паддинг 12/14**; подпись 12px muted.
10. **Table** — заголовки 11px uppercase muted с нижней линией divider; строки с линией text@8%, hover text@4%.

## Modals
- **М1 · Услуга — создание и редактирование** (600px). Одна форма для обоих режимов; в режиме редактирования показывается ghost «Удалить услугу» слева. Поля: клиент (select), дата, время, длительность, услуга, стоимость, валюта, адрес (select + icon-кнопка «+» для ввода нового адреса), комментарий; два `StatusButton`; разделитель; блок «Поля категории» — для репетитора «Домашнее задание» (textarea), для тренера упражнения + адрес зала, для тату/бьюти — текущий проект, референсы, результат.
- **М3 · Клиент — создание и редактирование** (600px). Имя, телефон, Telegram, услуга по умолчанию, цена занятия, дата и время первого занятия, комментарий; разделитель; «Поля категории»: репетитор — предмет и уровень; тренер — цель и ограничения; тату — проект и зона; бьюти — тип услуги и аллергии. В режиме редактирования — ghost «Удалить клиента».
- **М5 · Предоплата** (520px). Select клиента с числом неоплаченных занятий; степпер (− значение +) с подписью «от 1 до N»; блок «Будут отмечены оплаченными» — список самых ранних неоплаченных занятий и «Итого»; primary «Оплатить» (disabled, если N = 0).
- **М6 · Пересечение по времени** (520px). Текст с конфликтующим занятием, блок «Свободные слоты рядом» (secondary-кнопки времени), действия: «Оставить 15:00» / «Изменить время».
- **М7 · Автозаполнение на 4 недели** (520px). Список из 4 будущих занятий с тегом «Не оплачено»; действия «Не сейчас» / «Создать 4 занятия». Показывается после сохранения клиента с датой и временем (репетитор, тренер).
- **М8 · Удаление** (460px) — подтверждение с числом связанных занятий; primary с фоном accent-700.
- **М9 · Несохранённые изменения** (460px) — «Вернуться» / «Закрыть».
- **М10 · Сброс приложения** (460px) — поле подтверждения «СБРОС», primary accent-700, по умолчанию disabled.
- **М11 · Новое упражнение** (520px) — название, подходы, повторы, вес; подпись о подстановке из прошлого выполнения.
- **М12 · Просмотр фото** — оверлей neutral-900@75%, подпись файла и клиента, кнопка закрытия, область фото radius 24, стрелки ‹ ›, лента миниатюр 56×56 (активная — обводка accent), зум колесом/пинчем.

## Interactions & behavior
- Смена статуса — тап по соответствующей кнопке в строке или на экране деталей; переключение мгновенное, цвет меняется по семантике.
- Фильтр периода на главной и в статистике — пересчёт списка/сумм без перехода.
- Пустые состояния: нет клиентов → предложить добавить клиента; нет занятий, но есть клиенты → предложить добавить занятие.
- Закрытие формы с изменениями → М9. Удаление → М8.
- При сохранении услуги/клиента с датой и временем: пересечение → М6; для репетитора и тренера после сохранения клиента → М7.
- Предоплата помечает оплаченными самые ранние неоплаченные занятия выбранного клиента.
- Hover/pressed/focus — по правилам токенов (см. Design tokens); собственных «браузерных» состояний не оставлять.

## State (минимум)
`serviceCategory`, `clients`, `services` (клиент, дата/время, длительность, услуга, цена, валюта, адрес, isPaid, isDone, категорийные поля), `addresses` (для селектора адресов), `exercises` (тренер), `photos`/`projects` (тату, бьюти), `feedPeriodFilter`, `statsPeriodFilter`, `selectedClientId`, `selectedServiceId`, `dialogState`.
